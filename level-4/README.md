# TaskFlow Dashboard - Level 4

## Project Overview

 I created a simple project called TaskFlow which is a responsive task management dashboard that fits for the Level 4 challenge of the Mastering CSS Layouts: Flexbox vs. Grid learning activity.

The project demonstrates the same dashboard layout using both "CSS Flexbox" and "CSS Grid". The dashboard follows the classic "Holy Grail layout" with a header, navigation bar, left sidebar, main content area, right sidebar, and footer.

The project also includes responsive layouts and simple JavaScript interactions.
